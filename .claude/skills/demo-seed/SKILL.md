# Demo Seed Skill

## Overview

デモ用シードデータの操作（投入・削除・リセット）を実行する。

対象コマンドはすべて `backend/` ディレクトリの npm スクリプト：

| スクリプト | 内容 |
|---|---|
| `db:demo:reset:local` | 削除 → 生成 → 投入（フルリセット） |
| `db:demo:local` | `demo-seed.sql` をDBに投入するだけ |
| `db:demo:delete:local` | `delete-seed.sql` でシードレコードを削除するだけ |
| `db:demo:generate` | `generate-demo-seed.mjs` を実行して SQL ファイルを生成するだけ |

---

## Steps

### 1. 意図の判定

ユーザーの発話から実行するコマンドを1つ決める。

| 発話の意図 | 使うスクリプト |
|---|---|
| リセット・入れ直し・やり直し・最新にする | `db:demo:reset:local` |
| 投入・流す・追加・入れる（削除なし） | `db:demo:local` |
| 削除・消す・クリア（投入なし） | `db:demo:delete:local` |
| SQL ファイルだけ生成（DB操作なし） | `db:demo:generate` |

迷ったときは `db:demo:reset:local`（フルリセット）を候補として提示する。

---

### 2. 実行前確認

削除を伴う操作（`reset` / `delete`）は実行前に1行で確認を取る：

```
デモデータを削除して再投入します（db:demo:reset:local）。よろしいですか？
```

投入のみ・生成のみの場合は確認不要で即実行してよい。

---

### 3. コマンド実行

`backend/` ディレクトリで `npm run <script>` を実行する。

```bash
cd backend && npm run db:demo:reset:local
```

---

### 4. 結果報告

実行結果（成功 / エラー）を1〜2行で報告する。
エラーが出た場合はメッセージを引用して原因を簡潔に伝える。
